Electricity Consumption Trend Analysis

A Data Science Mini Project developed by Aryan Raj.

Project Overview

This project analyses electricity consumption patterns using Python and interactive visualizations. It helps users understand daily and monthly electricity usage trends.

Features

- Daily electricity consumption analysis
- Monthly consumption analysis
- 7-day moving average
- Usage distribution visualization
- Date range filtering
- CSV dataset upload
- Downloadable consumption records

Technologies Used

- Python
- Pandas
- NumPy
- Plotly
- Streamlit

How to Run

Install dependencies:

pip install -r requirements.txt

Run the dashboard:

streamlit run streamlit_app.py

Dataset

The project supports CSV datasets. Demonstration data is simulated and should not be treated as actual electricity meter readings.
