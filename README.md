
# Electricity Consumption Trend Analysis

## Project Overview
This project analyses electricity consumption
patterns using Python and Data Science.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

## Features
- Electricity consumption analysis
- Average consumption calculation
- Maximum and minimum usage
- Moving average calculation
- Data visualization

## Dataset
Illustrative monthly electricity consumption
data for 2026.
